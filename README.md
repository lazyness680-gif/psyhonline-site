## 🎯 Решаемая задача

Человек с тревогой, выгоранием или сложностями в отношениях обычно долго откладывает обращение к психологу. Его останавливают три барьера:

1. **«А это про меня?»** — непонятно, с чем вообще работает специалист.
2. **«А ему можно доверять?»** — нет доказательств квалификации и живого опыта других людей.
3. **«Сколько это стоит и как всё устроено?»** — мутные условия пугают сильнее цены.

Сайт снимает все три барьера за одно посещение страницы:

- посетитель **узнаёт себя** в описаниях состояний — и понимает, что попал по адресу;
- **доверие** складывается из галереи дипломов и сертификатов, отзывов, статей и живого «человеческого» тона;
- **прозрачные условия**: цена первой встречи, её длительность и свободные слоты показаны до записи;
- **запись за минуту**: одна кнопка «Записаться» → модальное окно с формой — без звонков и переписки.

Итог: мягко ведёт человека от состояния «мне плохо, но страшно куда-то идти» до отправленной заявки на консультацию.

## ⚙️ Функциональность

- **Адаптивная вёрстка** — от 320 px до широких десктопов; на телефоне — нижняя панель быстрой записи (скрывается, когда на экране блок записи).
- **Модальные окна на нативном `<dialog>`** — окно записи и галерея документов: закрытие по фону и Escape, блокировка прокрутки страницы, fallback для старых браузеров.
- **Галерея документов** — полноэкранный просмотр сканов: стрелки, свайп на тач-устройствах, миниатюры `thumbs/` + полные версии.
- **FAQ-аккордеон** — плавное раскрытие вопросов.
- **Автодедлайн акции** — скрипт рассчитывает ближайшее воскресенье и подставляет дату в блок условий.
- **Анимации появления** — секции «проявляются» при скролле; отключаются при `prefers-reduced-motion: reduce`.
- **Форма записи через Яндекс Формы** — iframe с автоподстройкой высоты; при отключённом JS кнопки открывают форму в новой вкладке.
- **Локальные шрифты** — Manrope и Lora (кириллица + латиница) в `woff2`; единственный внешний запрос — `forms.yandex.ru`.
- **SEO-база** — meta-описание, Open Graph, JSON-LD.

## 🚀 Запуск

Самый простой способ — открыть `index.html` в браузере.

Если нужен локальный сервер (проверка путей и кэша), выполните из папки проекта:

```powershell
# Вариант 1: если установлен Python
python -m http.server 8000

# Вариант 2: если установлен Node.js
npx serve .
```

Затем откройте `http://127.0.0.1:8000/`.

## 📝 Форма записи (Яндекс Формы)

По кнопкам «Записаться» открывается модальное окно с встроенной формой:

- iframe растянут на 100 % ширины модального окна, на телефоне — на всю ширину экрана;
- `embed.js` Яндекса автоматически подстраивает высоту под содержимое;
- при первом открытии форма перезагружается в видимом окне для корректного расчёта высоты;
- если JavaScript отключён — форма открывается в новой вкладке;
- при переезде формы на новый адрес замените URL во всех кнопках `data-open-booking` и в `iframe` внутри `#bookingDialog`.

## 🔒 Конфиденциальность

- Скриншоты отзывов с именами и фото клиентов **в репозиторий не входят** — на сайте только обезличенные тексты.
- Политика конфиденциальности открывается из подвала и блока записи; в ней указано, что заявки принимаются через Яндекс Формы.
- Согласие на обработку данных настраивается внутри самой Яндекс Формы.
- Не публикуйте отзывы, по которым человека можно узнать, без его письменного согласия.

## 🔍 SEO и публикация

- После выбора домена: абсолютные `og:image`, `og:url`, `<link rel="canonical">`.
- Добавить `robots.txt` и `sitemap.xml`.
- Подключить Яндекс.Метрику / Google Analytics при необходимости (по умолчанию не подключены).
- HTTPS + редирект с `www`; проверка в Яндекс.Вебмастере и Search Console.
- Для локального SEO — город/регион и `areaServed` в JSON-LD.
